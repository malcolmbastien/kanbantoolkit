Help

The short answers, here rather than in an inbox. The longer list is task 158; these are the three things people ask for first.

Getting in

On an instance somebody runs, sign in with the account you already have — Google, Microsoft, or an identity provider the operator configured. An invitation arrives as a link; it works once, and you can be sent another. There is no account to create on this site: if nobody has installed an instance yet, that is the first step.

Taking a workspace with you

Open the board, choose More → Export in the workspace toolbar, and the file lands in your downloads. It is the workspace: boards, lanes, cards, placements, the history and all. Nothing is left behind, because nothing is generated — the file is the data.

Closing a workspace

Admin → This workspace → Delete this workspace. The workspace's administrator is the only person who can do it, the workspace's name is typed to confirm, and the accounts that belong to it are deleted with it. Export first if you may want it again: there is no undo.

Running it yourself

Clone, build, run: the install page has the three commands and what the process reads. Upgrading, backing up and restoring have a chapter each in the documentation — the docs live with the code, so they are the same version as the software you are running.

Reaching a person

support@flowline.example — answered within two working days. Security reports go to security@flowline.example, and are answered faster.
