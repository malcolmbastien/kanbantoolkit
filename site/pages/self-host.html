Self-host

Flowline is one codebase with two entries. The same routes, the same rules and the same database schema run on a machine you control: one Node process, one SQLite file, and a directory of static files.

What it costs you

A small server, a reverse proxy for TLS, and somebody who can run a backup. There is no Durable Object to lean on: the live channel is the process's own socket server, and the fallback is the poll the app already makes.

The packaging, the licence and the page you are reading are task 160; the runbook is task 128.
