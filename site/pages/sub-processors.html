Sub-processors

The services the hosted product relies on, and what each one sees. The current list, checked against the deployment's configuration, is task 150.

The list

  • The identity providers — Google and Microsoft, or whichever an operator configures. They see that you signed in; they do not see your workspace.
  • The host — the machine the deployment runs on, and the database it holds.
  • The error log — a message, a stack, a path and a build. Never a query string, never an address.
