If you run your own

This list is not yours. A self-hosted instance's processors are the ones its operator chose — the machine, the identity provider they configured, the database file, their own error log — and the operator is the controller of that data. The table above is the shape to copy, not a relationship to inherit.

There is no data processing agreement to sign with this project, because there is no processing: it ships software, and you run it. If you process somebody else's data on an instance you operate, your own agreement is the one that matters.

Changes

When this deployment adds or removes a processor, the release note for the tag says so. A self-hosted instance changes when its operator changes it, and nobody here can promise them notice.
