# Security policy

Kanban Toolkit is self-hosted software, run by one person. I follow the usual practices and I can offer no
guarantees; help from somebody who knows more about this than I do is very welcome.

## Reporting a vulnerability

[Open an issue](https://github.com/malcolmbastien/kanbantoolkit/issues/new/choose) — the same tracker as a
bug. If the detail is the dangerous part, say only that you have a report and we will take the rest
somewhere private before you post it.

Please do not test against somebody else's instance: run your own.
